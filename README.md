# Signature Kiosk

Система для планшетов-киосков (freekiosk): показ рекламных слайдов и проведение
подписанта по документу с чекбоксами и подписью — с управлением из веб-админки в
реальном времени через **ASP.NET Core + SignalR**.

```
 Планшет (freekiosk)                     Оператор (браузер)
 https://signalr.zrobim.it/?device=t1    https://signalr.zrobim.it/admin
          │  WSS (SignalR)                        │  HTTPS + WSS
          ▼                                       ▼
 ┌──────────────────────  nginx (TLS, ваш)  ──────────────────────┐
 │                     proxy → 127.0.0.1:5080                      │
 └───────────────────────────────┬────────────────────────────────┘
                                  ▼
                   ASP.NET Core (Kestrel, :5080)
        ┌───────────────┬──────────────────────┬────────────────┐
        │   KioskHub     │  REST API + вход     │  Статика (SPA) │
        │  (SignalR)     │  (пароль в админку)  │  плеер+админка │
        └───────┬────────┴──────────┬───────────┴────────────────┘
                │                    ▼
                │      Файловое хранилище: /var/lib/signaturekiosk
                │      (картинки, подписи, состояние — без БД)
                ▼
        Группы: "kiosks", "dev:<id>", "admins"
```

## Что умеет

- **Слайд-шоу (реклама).** В админке загружаете картинки, отмечаете нужные,
  задаёте интервал → «Сохранить и показать» → слайды **моментально** появляются
  на планшете и листаются по кругу.
- **Адресность.** Контент можно отправить **на конкретный планшет или на все
  сразу** (селектор «Планшет» вверху). Планшеты видны на вкладке «Планшеты»
  (онлайн/офлайн), их можно переименовать.
- **Документ для подписанта.** Кнопка «Показать документ подписанту» переключает
  выбранный планшет с рекламы на документ: страницы с текстом, кнопки
  **Далее/Назад**, **обязательные чекбоксы**, затем экран **подписи**
  (`signature_pad`) и «Спасибо». Документ и его тексты/чекбоксы редактируются в
  админке (вкладка «Документ»).
- **Приём подписей.** После нажатия **ПОДПИСАТЬ** отмеченные пункты и картинка
  подписи уходят на сервер и **сразу** появляются в админке (вкладка «Подписи»):
  видно, что именно отметил клиент, и его роспись. Планшет автоматически
  возвращается к рекламе.
- **Восстановление состояния.** При перезагрузке/переподключении планшет сам
  подтягивает актуальный экран (слайды или документ).

## Технологии

- **Backend:** ASP.NET Core 8, SignalR. Без внешних NuGet-зависимостей.
- **Хранилище:** файлы + JSON на диске (никакой БД — просто для прототипа).
- **Frontend:** чистый JavaScript (без сборщика). Библиотеки `@microsoft/signalr`
  и `signature_pad` отдаются локально из `wwwroot/lib` (не с CDN — надёжнее на
  планшете). В git не хранятся — подтягиваются скриптом `deploy/fetch-libs.sh`
  при деплое (и один раз для локальной разработки).

## Локальный запуск

Нужен .NET 8 SDK.

```bash
bash deploy/fetch-libs.sh          # один раз: подтянуть signalr + signature_pad
cd src/SignatureKiosk
AdminPassword=test123 DataDir=./_data ASPNETCORE_URLS=http://127.0.0.1:5080 dotnet run
```

- Плеер (что открывает планшет): <http://127.0.0.1:5080/?device=tablet-1&name=Стенд>
- Админка: <http://127.0.0.1:5080/admin> (пароль из `AdminPassword`)

## Планшет (freekiosk)

В freekiosk укажите один URL с уникальным `device`:

```
https://signalr.zrobim.it/?device=tablet-1&name=Ресепшн
https://signalr.zrobim.it/?device=tablet-2&name=Кабинет
```

Планшет открывает этот URL, подключается к хабу и дальше **никуда не
переходит** — все переключения (реклама ↔ документ) приходят по SignalR.

## Развёртывание

См. [`deploy/README.md`](deploy/README.md). Кратко — на сервере:

```bash
sudo ADMIN_PASSWORD='ваш-пароль' bash deploy/deploy.sh
```

затем подключить nginx по [`deploy/nginx-signalr.zrobim.it.conf`](deploy/nginx-signalr.zrobim.it.conf).

## SignalR-контракт (хаб `/hub/kiosk`)

**Планшет → сервер**
- `RegisterKiosk(deviceId, name) → CurrentCommand` — регистрация, возвращает
  текущий экран (`slides`/`document`).
- `FinishDocument()` — вызывается после подписи, возвращает планшет к рекламе.

**Админка → сервер**
- `RegisterAdmin()` — подписка на события.

**Сервер → планшет**
- `ShowSlides({ images[], intervalSec })`, `ShowDocument(documentConfig)`.

**Сервер → админка**
- `DevicesChanged()` — список/статусы планшетов изменились;
- `SignatureReceived({...})` — пришла новая подпись.

Подпись отправляется отдельным `POST /api/sign` (картинка PNG), сервер уведомляет
админку через `SignatureReceived`.

## Хранилище данных (`DataDir`)

```
images/            загруженные картинки
images.json        их список
states.json        состояние: default + переопределения по планшетам
devices.json       известные планшеты (id, имя)
document.json      конфиг документа для подписанта
signatures/<id>/   meta.json (пункты) + signature.png (роспись)
```
