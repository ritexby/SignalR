# HELIX SignTablet

Система для планшетов-подписантов: показ рекламных слайдов и проведение клиента по
документу (тексты → чекбоксы → подпись), с управлением из веб-админки в реальном
времени через **ASP.NET Core + SignalR** и генерацией **PDF** по каждой подписи.

Планшеты работают через киоск-браузер **freekiosk** (Android WebView): открывают
один URL, активируются кодом и дальше получают команды по защищённому WebSocket.

```
 Планшет (freekiosk)                         Оператор (браузер)
 https://signalr.zrobim.it/?enroll=CODE      https://signalr.zrobim.it/admin
          │  WSS (SignalR, токен устройства)          │  HTTPS (пароль)
          ▼                                           ▼
 ┌───────────────────  Nginx Proxy Manager (TLS)  ───────────────────┐
 │                     proxy → 10.1.1.189:5080                        │
 └───────────────────────────────┬───────────────────────────────────┘
                                  ▼
                   ASP.NET Core (Kestrel, :5080)  ── .NET 10
      ┌───────────────┬──────────────────────┬─────────────────────┐
      │  KioskHub      │  REST API + Auth     │  Статика (SPA)      │
      │  [Authorize]   │  admin / kiosk / ext │  плеер + админка    │
      └───────┬────────┴──────────┬───────────┴─────────────────────┘
              │                    ▼
              │      Файловое хранилище: /var/lib/signaturekiosk
              │      (устройства, группы, места, картинки, подписи, PDF)
              ▼
      Группы SignalR: "kiosks", "dev:{id}", "grp:{id}", "admins"
```

## Возможности

- **Слайды (реклама).** Загрузка картинок, выбор, интервал; «Сохранить» — контент
  моментально появляется на планшете и листается по кругу.
- **Документ подписания.** Страницы с текстом, кнопки **Далее/Назад**, обязательные
  **чекбоксы**, экран подписи (`signature_pad`) и «Спасибо». Тексты/чекбоксы
  редактируются в админке.
- **PDF по каждой подписи.** После подписания формируется PDF (текст документа +
  отмеченные пункты + подпись клиента внизу) и складывается в папку `pdf/`. Кнопка
  «Скачать PDF» в админке. Кириллица — через встроенный шрифт DejaVu.
- **Безопасное подключение планшетов.** Активация одноразовым **кодом** → устройство
  получает постоянный **токен**; хаб пускает только устройства с валидным токеном
  (`[Authorize]`). Личность и группы берутся из токена, не из URL. **Блокировка**
  в один клик отзывает доступ.
- **Группы и адресная отправка.** Контент отправляется **Всем / Группе / Конкретному
  планшету**.
- **Рабочие места.** Первоклассная сущность с внешним ID; код активации можно сразу
  привязать к месту; подпись фиксирует, на каком рабочем месте она сделана.
- **Внешнее API по ключу** (`/api/ext/*`): список планшетов и статус, создание кодов
  активации, привязка «планшет ↔ место» — для интеграции с ERP/CRM/учётом.
- **«Опознать».** Планшет крупно показывает номер на экране — понять, какой это
  физически.
- **Live-обновления в админке** (новые подписи, статусы планшетов) через SignalR.

## Технологии

- **Backend:** .NET 10 (LTS), ASP.NET Core, SignalR, PDFsharp 6.2.4.
- **Frontend:** чистый JavaScript без сборщика; `@microsoft/signalr` 10 и
  `signature_pad` 5 отдаются локально (подтягиваются `deploy/fetch-libs.sh`).
- **Хранилище:** файлы + JSON на диске (прототип, без внешней БД).
- **Развёртывание:** self-contained сборка + systemd, за Nginx Proxy Manager (TLS).

## Как работает планшет

1. В админке (вкладка **Планшеты**) генерируется одноразовый код активации.
2. В freekiosk указывается адрес `https://signalr.zrobim.it/?enroll=КОД`.
3. Планшет обменивает код на постоянный токен, запоминает его и подключается к хабу.
   Тот же URL работает и дальше — токен сохранён, код повторно не нужен.
4. Потеряли планшет → «Заблокировать» в админке, токен перестаёт пускать.

## Админка (`/admin`, вход по паролю)

Вкладки: **Слайды** · **Документ** · **Подписи** · **Планшеты** · **Группы** ·
**Места** · **API-ключи**. Вверху — селектор адресата «Кому» (Все / группа / планшет).

## Безопасность

- Хаб под `[Authorize]`; аноним отклоняется. Токен устройства идёт в `access_token`
  при WebSocket-рукопожатии; админка — по cookie логина.
- Секреты устройств и API-ключи хранятся только как SHA-256 хэши; токены отзываемы.
- Подписи и данные клиентов доступны только через админку (за паролем); исходники и
  конфиг по HTTP не отдаются. Пароль админки — в `/etc/signaturekiosk.env` (права 640).

## SignalR-контракт (хаб `/hub/kiosk`, требует авторизации)

- Планшет: `RegisterKiosk() → CurrentCommand` (личность из токена), `FinishDocument()`.
- Админка: `RegisterAdmin()` (только с админ-кукой).
- Сервер → планшет: `ShowSlides`, `ShowDocument`, `Identify`.
- Сервер → админка: `DevicesChanged`, `SignatureReceived`.

Подпись отправляется отдельным `POST /api/sign` (device-токен), сервер уведомляет
админку и генерирует PDF.

## Внешнее API (`/api/ext/*`, заголовок `X-Api-Key`)

- `GET /api/ext/devices` — планшеты, статус, привязка к месту.
- `GET|POST /api/ext/workstations` — рабочие места.
- `POST /api/ext/enrollments` — код активации (можно с `workstationExternalId`).
- `PUT /api/ext/devices/{id}/workstation` — сменить привязку по внешнему ID места.

## Хранилище (`DataDir`, по умолчанию `/var/lib/signaturekiosk`)

```
images/            картинки          images.json     их список
devices.json       устройства        groups.json     группы
workstations.json  рабочие места     enrollments.json коды активации
apikeys.json       ключи             states.json     состояние экранов
document.json      конфиг документа
signatures/<id>/   meta.json + signature.png
pdf/<id>.pdf       готовые PDF подписей
```

## Локальный запуск

Нужен .NET 10 SDK.

```bash
bash deploy/fetch-libs.sh          # один раз: подтянуть signalr + signature_pad
cd src/SignatureKiosk
AdminPassword=test123 DataDir=./_data ASPNETCORE_URLS=http://127.0.0.1:5080 dotnet run
```
- Плеер (что открывает планшет): <http://127.0.0.1:5080/> (первый раз — экран активации)
- Админка: <http://127.0.0.1:5080/admin>

## Развёртывание

См. [`deploy/README.md`](deploy/README.md). Кратко — на сервере:

```bash
sudo ADMIN_PASSWORD='ваш-пароль' bash deploy/deploy.sh
```

`deploy.sh` ставит .NET 10, тянет библиотеки, собирает self-contained сборку,
создаёт systemd-сервис. Обратный прокси (Nginx Proxy Manager) → `THIS_HOST:5080`.
