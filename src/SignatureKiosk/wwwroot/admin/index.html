Signature Kiosk

Слайды (реклама)

Отметьте картинки для показа. Номер на картинке — её порядок в слайд-шоу. «Сохранить и показать» моментально отправит их на выбранный планшет.

Документ для подписанта

Отредактируйте страницы, тексты и чекбоксы. «Показать документ» переключит выбранный планшет с рекламы на этот документ.
