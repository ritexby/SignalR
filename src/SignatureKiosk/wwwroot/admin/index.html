Вход в админку

HELIX SignTablet

Слайды (реклама)

Контент отправится на выбранного вверху адресата («Кому»): все / группа / конкретный планшет. Номер на картинке — её порядок.

Документ для подписанта

«Показать документ» переключит выбранного вверху адресата с рекламы на этот документ.

Полученные подписи

Планшеты

Новый планшет добавляется кодом активации: сгенерируйте код, введите его на планшете один раз — он получит защищённый доступ. Идентификатор в URL больше не нужен.

Группы планшетов

Объединяйте планшеты в группы, чтобы отправлять контент сразу на группу (выбор «Кому» вверху).

Рабочие места

Внешний ID — ключ вашей учётной системы (например WS-204). По нему привязка «планшет ↔ место» доступна из внешнего API.

API-ключи (внешняя система)

Ключ даёт внешней системе доступ к /api/ext/*: список планшетов, статус, привязка к местам, создание кодов активации. Ключ показывается один раз при создании.
