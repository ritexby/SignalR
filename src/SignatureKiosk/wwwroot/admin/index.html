HELIX SignTablet

Слайды (реклама)

Реклама отправится выбранному адресату («Кому»): все / группа / конкретный планшет. Выбор здесь не зависит от вкладки «Документ». Номер на картинке - её порядок.

Документ для подписанта

«Показать документ» переключит выбранного здесь адресата с рекламы на этот документ. Этот выбор независим от вкладки «Слайды»: например, реклама идёт на все планшеты, а документ - только на один.

Полученные подписи

Планшеты

Новый планшет добавляется кодом активации: сгенерируйте код, введите его на планшете один раз - он получит защищённый доступ.

Группы планшетов

Объединяйте планшеты в группы, чтобы отправлять контент сразу на группу (выбор «Кому» на вкладках «Слайды» и «Документ»).

Рабочие места

Внешний ID - ключ вашей учётной системы (например WS-204). По нему привязка «планшет ↔ место» доступна из внешнего API.

API-ключи (внешняя система)

Ключ даёт внешней системе доступ к /api/ext/*: список планшетов, статус, привязка к местам, создание кодов активации. Ключ показывается один раз при создании.
